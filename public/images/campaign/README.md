# SICARÚ · Fotografías de campaña — SOLO PREVIEW

Esta carpeta se reserva para las dos fotografías conceptuales del nuevo banner.
La composición, el morado y el encuadre se aceptaron como base visual; **los
archivos no están autorizados como material fotográfico definitivo**.

Para habilitar el laboratorio privado `/qa/banner-candidato`, subir los dos
WebP originales, **sin modificar ni renombrar sus bytes**, con estos nombres:

- `sicaru-hero-desktop.webp` — 1774 × 887 px, 120978 bytes.
- `sicaru-hero-mobile.webp` — 1174 × 887 px, 113096 bytes.

El archivo `docs/qa/banner-candidato-assets.json` conserva SHA-256 y dimensiones
para validar su integridad. El CI rechazará un archivo faltante, manipulado
o con dimensiones incorrectas.

**No habilitar `CampaignHeroCandidate` en la portada real antes de aprobar
la fotografía definitiva, revisión de Safari/desktop/móvil, catálogo y rollback.**

Sin compras, precios, inventario, backend o pagos afectados.
